# 产品设计 · FLiNG Vault（风灵月影修改器库）

> 版本 1.0 · 状态：已实现并验收 · 数据源：https://flingtrainer.com/

## 1. 背景与问题

FLiNG（风灵月影）的修改器以「单文件 exe + 官网逐条发布」的方式分发。玩家实际面对的摩擦是：

1. 每次都要回官网翻列表、找游戏、点进详情页、再下载，站点全英文且广告多；
2. 下载下来的文件名是 `Phantom.Blade.Zero.v1.0.Plus.36.Trainer-FLiNG.exe` 这类机器名，散落在「下载」文件夹，无法检索；
3. 游戏更新后修改器会失效，但没有任何提醒机制，玩家只能凭记忆回官网核对；
4. 启动前常常忘记管理员权限，或忘了先开游戏。

本产品把这条链路收进一个桌面客户端：**发现 → 下载 → 归库 → 更新 → 启动**。

## 2. 目标与非目标

### 目标（MVP）

| 编号 | 目标 | 验收标准 |
|---|---|---|
| G1 | 从官网同步目录 | 一次同步拉到 700+ 条目，含封面、选项数、游戏版本、最后更新时间 |
| G2 | 下载并安装到本地库 | 下载进度可见、可取消；安装后文件落在统一目录，记录版本/大小/时间 |
| G3 | 本地库管理 | 支持搜索、排序、收藏、标签分类、删除、打开所在文件夹 |
| G4 | 更新检测 | 对比官网「Last Updated」与帖子修改时间，标记可更新项 |
| G5 | 快捷调用 | 全局热键 Ctrl+Alt+F 唤出面板，输入即搜、回车启动；托盘常驻 |
| G6 | 视觉一致 | 配色/密度/控件形态与修改器本体一致（#1E2021 底、#FF8000 强调、方角细边） |

### 非目标（本期明确不做）

- 不做修改器功能本身的替代（不注入进程、不修改内存）；
- 不做游戏库/游戏启动器，不扫描 Steam 库；
- 不做账号体系、云同步、社区分享；
- 不做官网论坛/评论抓取；
- 不支持 macOS / Linux（修改器本身就是 Windows PE）。

## 3. 用户与场景

**主场景**：玩家在游戏更新后想起修改器失效 → 打开 FLiNG Vault → 侧栏「可更新」出现红点 → 一键更新 → 启动。

**次场景**：游戏已开着，玩家按 Ctrl+Alt+F → 输入 "phantom" → 回车 → 修改器以管理员身份弹出。

**第三场景**：玩家装了 20 个修改器，按「动作」「RPG」打标签，侧栏按标签筛选。

## 4. 信息架构

```
左侧导航                     主区                        右侧详情抽屉
├─ 全部修改器 (catalog)      ├─ 搜索 / 排序 / 同步       ├─ 封面 + 标题 + 元信息
├─ 已安装                    ├─ 卡片网格（封面 + 状态）   ├─ 启动 / 更新 / 文件夹 / 删除
├─ 可更新                    └─ 无限滚动加载             ├─ 元信息表（版本/大小/时间）
├─ 收藏                                                  ├─ 快捷键表（与修改器一致）
├─ 分类（标签，动态）                                     ├─ 标签 + 备注
└─ 设置 / 官网
```

## 5. 关键流程

### 5.1 首次使用
1. 启动 → 目录为空 → 空状态引导「同步官网目录」；
2. 同步（分页并发 3，约 8 个请求 / 700+ 条）→ 卡片墙出现；
3. 点击卡片 → 抽屉展示快捷键表与文件信息 → 「下载并安装」；
4. 完成后状态变「已安装」，卡片右下角出现「启动」。

### 5.2 更新
检查更新 → 一次 `include=` 批量请求覆盖全部已安装项 → 比对 `lastUpdated` 与 `postModified` → 有差异标记 `updateAvailable` → 侧栏计数 + 卡片徽标 → 抽屉内「更新」重新下载覆盖。

### 5.3 快捷启动
全局热键 → 无边框置顶窗口（透明、居中）→ 列表按「收藏 → 最近启动」排序 → 输入过滤 → ↑↓ 选择 → Enter 启动并隐藏面板。

## 6. 视觉规范（与修改器本体对齐）

| 令牌 | 值 | 来源 |
|---|---|---|
| 画布底色 | `#1E2021` | 修改器窗口背景采样 |
| 主强调色 | `#FF8000` | 修改器标题橙 |
| 深色面板 | `#17191A` / `#101213` | 标题栏 / 数值输入框 |
| 描边 | `#2A2D2E`，1px | 修改器分隔线 |
| 主文字 | `#E8E9EA` | 选项名 |
| 次文字 | `#8B8E8F` | 快捷键列灰 |
| 圆角 | 2px | 修改器控件为直角 |
| 字体 | Segoe UI + 微软雅黑；元信息用等宽 | 修改器同为系统字体 |
| 密度 | 行高 26–32px，卡片 250px 宽 | 修改器列表紧凑 |

明确不采用的做法：渐变大面积背景、圆角卡片阴影堆叠、彩色 emoji、悬浮玻璃拟态。深度只用「1px 描边 + 底色差」表达。

## 7. 度量

- 首次同步成功率（网络失败可重试 3 次）
- 下载完成率 / 平均耗时（1.7 MB 级文件，正常 < 5s）
- 更新检测命中率
- 快捷面板唤起到启动的按键数（目标 ≤ 4 次）

## 8. 后续可选
